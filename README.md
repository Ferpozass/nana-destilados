# NÄNÄ ナナ — Destilado de agave

Landing page bilingüe (español / 日本語) de NÄNÄ, destilado 100% de agave hecho a mano en Querétaro, México, para su distribución en Tokio, Japón.

Proyecto de Mercadotecnia Internacional · Universidad Tecnológica de Querétaro.
Creado por Guillermo Martínez, Betsabé Ortiz, Fernanda Ortiz y Ton.

- `index.html` — landing principal
- `historia.html`, `blog.html`, `legal.html` — páginas del pie de página
- HTML, CSS y JavaScript puros, sin dependencias

Las imágenes son representaciones conceptuales del producto; algunas escenas se generaron con IA.
